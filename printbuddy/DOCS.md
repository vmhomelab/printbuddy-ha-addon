# Printbuddy

Printbuddy provides a self-hosted dashboard for managing Bambu Lab, Klipper, and Mainsail/Moonraker 3D printers.

After starting the add-on, open the Web UI from the add-on page or the Home Assistant sidebar.

## First start

1. Start the add-on.
2. Open **Web UI**.
3. Add your printers in Printbuddy.
4. For virtual-printer or Bambu compatibility features, use the Home Assistant host address when a printer needs to connect back to Printbuddy.

## Backups

Home Assistant add-on backups include the add-on `/data` volume. Printbuddy stores data under `/data/printbuddy` and logs under `/data/logs`.
